# exisolinux
A small gui script to help linux users convert xbox 360 iso files for use on a devkit

Depends on zenity and wine

## Includes:

X360PkgTool by xorloser from http://xorloser.com/blog/?p=395

xextool by xorloser from http://xorloser.com/blog/?p=395


# How to open interface
Python3 required to run this script. Open the terminal and type one of this for your system:

Arch / Manjaro / CachyOS / EndeavourOS: sudo pacman -S tk

Fedora: sudo dnf install python3-tkinter

Debian / Ubuntu / Mint: sudo apt install python3-tk

openSUSE: sudo zypper install python3-tk

------------
In terminal type: python patch360_gui.py
